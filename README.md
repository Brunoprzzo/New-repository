# Gym Website (Node.js + Express)

A modern responsive Gym / Fitness website built with HTML, CSS, JavaScript, and Node.js.

## Project structure

```text
gym-website
│
├── server.js
├── package.json
├── /public
│   ├── index.html
│   ├── /css
│   │   └── style.css
│   ├── /js
│   │   └── script.js
│   └── /images
```

## Run locally

```bash
cd gym-website
npm install
node server.js
```

Open: <http://localhost:3000>
